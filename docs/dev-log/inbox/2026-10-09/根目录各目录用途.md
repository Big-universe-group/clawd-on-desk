# 根目录各目录用途

- 日期：2026-10-09
- 类型：问答
- 分支 / 提交：无

## 问题
根目录除了 src 和 node_modules 为何这么多目录，各自用途。

## 结论 / 回答
- 进安装包的只有 `src/`、`hooks/`、`themes/`、`extensions/`、`pwa/` 和 `assets/` 的一部分（看 `package.json` 的 `build.files` / `asarUnpack`）
- `test/` `scripts/` `build/` `ci/` `docs/` `tools/` `perf/` 只在开发 / 构建 / CI 用
- 可删候选：`perf/`、`tools/`、`docs/plans|investigations|releases`、`assets/gif|videos|screenshot-*`；随功能删：`ci/`（Linux）、`pwa/`（手机预览）
