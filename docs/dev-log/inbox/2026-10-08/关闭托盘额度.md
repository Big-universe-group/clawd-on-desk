# 关闭托盘额度

- 日期：2026-10-08
- 类型：实现（配置）
- 分支 / 提交：未提交（只改本机 prefs）

## 问题
关闭系统托盘中的额度展示。

## 结论 / 回答
- 托盘额度由 `quotaTrayEnabled` 控制（默认 false），需与 `sessionHudShowQuota` 同时为 true 才显示
- pro 的 `clawd-prefs.json` 显式写成 `quotaTrayEnabled: false`；mini 本来就是 false
- 发现坑：20:23 在上游 `main` 分支跑过一次 clawd，`prefs.save()` 只写当前 schema 的键，fork 独有的 7 个键被剥掉（quotaAlerts* / soundRepeat* / flashEffect）

## 改动
- `~/Library/Application Support/clawd-on-desk/clawd-prefs.json`（pro）：`quotaTrayEnabled=false`

## 对需求的影响
无（只是关闭现有功能）。

## 待办
被剥掉的提示音循环 / 托盘闪烁设置需在设置里重新调整。
